What's new in v1.3.0 across the Extension and Companion Server.

🎬

PO-Token Anti-Bot & Playlist Engine

  • PO-Token Auto-Injection: Automatically captures live session PO-Tokens and forwards them to the backend to bypass YouTube anti-bot limits.
  • Playlist Queue & Rate Throttling: Processes video batches sequentially with smart sleep intervals to prevent HTTP 429 rate limit bans.
  • Companion Server Version Check: Extension pings companion status and displays a clear warning if the server installer is older than v1.3.0.
  • YouTube Shorts & Modal Upgrades: Maintains full Shorts action bar integration and draggable screen clamping.

Companion Server & Engine (v1.3.0)

Companion Server v1.3.0 Update Required!
  • PO-Token Parameter Support: Ingests PO-Tokens and passes --extractor-args youtube:po_token=web+... to yt-dlp.
  • 100% English Installer & Dialogs: All maintenance wizard dialogs and native folder picker titles are standardized in English.
  • Zero-Disk Cookie & Token Security: Processes session cookies and tokens exclusively in RAM with 0-byte disk footprint.
  • Engine & Dependency Alignment: Guarantees smooth 1080p, 4K, 60fps and audio processing across Windows & Linux.
